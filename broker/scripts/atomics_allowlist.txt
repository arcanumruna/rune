# atomics_allowlist.txt — the ONLY places std::atomic / locks / memory-ordering
# primitives may appear in production code (scripts/check_no_atomics.py,
# ctest NoAtomicsOrMutexesOutsideAllowlistRegression).
#
# Format:  <path> | <token on the offending line, or *> | <CATEGORY> | <reason>
# CATEGORY:
#   RING     — inside a ring-buffer implementation (permanent).
#   CLEANER  — the off-thread LogCleaner/compaction channel (permanent, user law).
#   SLICE-B  — TEMPORARY: F9 slice B converts these, then deletes the entry.
#   UNSCOPED — TEMPORARY: outside slice A and slice B as briefed; must be
#              scheduled + converted (never add new ones to dodge the guard).
# A stale entry (matches nothing) FAILS the guard: delete entries as sites go.
