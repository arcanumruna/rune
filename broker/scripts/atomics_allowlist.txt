# memory-ordering / blocking primitives may appear (scripts/check_no_atomics.py,
# ctest NoAtomicsOrMutexesOutsideAllowlistRegression).
#
# Format:  <path> | <normalized line> | <count> | <CATEGORY> | <reason>
#   normalized line = the hit line's code, trailing comment removed, whitespace
#   collapsed.  The number of such lines in <path> must EQUAL <count>: an extra
#   copy or a missing one fails.  No wildcards.
# CATEGORY:
#   RING        — inside a ring-buffer implementation (permanent).
#   CLEANER     — the off-thread LogCleaner/compaction channel (permanent, user law).
#   CRASH-ORDER — compiler-only barrier ordering stores into a single-writer
#                 mmap'd file (not shared state; coordinator ruling F9a r1).
#   CPU-HINT    — spin-wait CPU hint (pause/yield) in BusySpinIdleStrategy; no
#                 shared state, no ordering contract (F9a r1: flagged by the
#                 widened inline-asm detection — pending ruling).
#   SLICE-B     — TEMPORARY: F9 slice B converts these, then deletes the entries.
#   UNSCOPED    — TEMPORARY: owned by neither slice yet; must be converted.
