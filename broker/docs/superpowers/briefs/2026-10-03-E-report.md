## 2. E2 harness (primary deliverable)

`libs/replication/tests/dr/DrHarness.h` + `DrIntegrationTest.cpp` → `rune_dr_integration_tests` (BUILD_TESTING, default run; whole suite ~0.1 s; 30× repeat clean).
- Real: `rune::storage::Log` on disk (recover/truncate), `PartitionReplica`, `ProducerStateManager` (rebuilt from the log), `rune::metadata::FailoverElection` (controller election over an omniscient position table; controller ISR changes only on a leader change, like DynamicBalancer).
- Transport seam: one endpoint per node; directed link cut, isolate, drop-next-N per frame kind, delivery delay; frames to/from a crashed node die with it.
- Storage seam: ProcessKill (page cache survives) / PowerLoss (each segment truncated to its durable extent = max of inline-synced extents across incarnations) / PowerLossTorn (adds a partial batch). Async io-backend flushes are not tracked (harness drives replicas with inline syncs).
- Produce path = worker path (`appendNoSyncRestamp` + `onLeaderLogAppended`), acks=all refused below min-ISR, acked when the served HW passes it under the same leader incarnation/epoch.
- Injected 1 ms clock, all drive loops capped; no sleeps, no threads.
- Kill-all definition: **process kill of every node** (page caches survive) → no acked loss. A simultaneous **power loss of all nodes** is outside the guarantee (fsync off by default); the suite asserts the cluster still recovers consistent (converged, no dups).

Tests (DrIntegration): HappyPath, UncleanShutdown_FollowerPowerLoss_TailRefetched, TornBatchAtTail_RecoveryDropsIt, LeaderCrash_UnflushedTail_PowerLoss_NoAckedLoss, LeaderCrash_UnackedTail_TruncatedOnRejoin, IsrShrinkExpand_UnderFaults_MinIsrGates, Kip101_DivergentTailsAcrossTwoFailovers, ProducerStateRebuildAfterCrash_NoDupNoOos, StaleLeaderFencing_SplitBrain_NoStaleAck, KillAll_ProcessKill_AcksAll_NoAckedLoss, KillAll_MinorityPowerLoss_NoAckedLoss, TotalPowerLoss_OutOfGuarantee_StillConsistent, LeaderMovedToLaggingIsrReplica_LossyDelayedLinks, PowerLoss_AcrossSegmentRolls_SealedSegmentsSurvive, DISABLED_Kip966_DoubleFault_UncleanFollowerPlusLeaderKill.
