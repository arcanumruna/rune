## Rulings I made
1. **C3 comes before U1/U2 for 28.**
   - The case: b is the oldest and a failed predecessor left a gap. Its head was never written, so a brand-new producer has no entry.
   - Without this ordering, the brief's "nothing acked + logStart 0 → U2" failed the followers that `EosOosRegression.FollowersOfATimedOutHeadAreResequencedNotFailedRegression` requires to be re-sequenced. That was a real regression, which I caught and fixed.
   - U therefore replaces only C4 (the next-in-line case). This is consistent with "applied like C".
2. **U1 requires `logStartOffset > 0`.** This follows the brief's U2 clause ("nothing acked and logStartOffset == 0" → unknown). An old broker's -1 never triggers U1.

- **Change:** rule U2 now re-sequences, the same as U1. U1 keeps its documented window unchanged.
