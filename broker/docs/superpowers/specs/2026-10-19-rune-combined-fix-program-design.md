## 2. Decisions (override the binding plan where they differ)

| # | Decision | Why it is the long-term design |
|---|---|---|
| M1 | `RUNE_AUTH=enabled` ⇒ every client session is TLS; plaintext Connect → `HandshakeFailed (29)`; `RUNE_TLS` build default ON; Enabled in a non-TLS build, any `RUNE_TLS_*`/`RUNE_REQUIRE_TLS` in a non-TLS build, or `RUNE_REQUIRE_TLS=false` with auth → refuse to start. Code-built test configs choose `ClientTransport::{RequireTls, PlaintextForTest}`; `parse()` never yields the latter, `main.cpp` refuses it. Replaces D12. | Only per-frame AEAD binds a frame to its session (X001, X002, X004, X066). |
| M2 | Client: `requireCrypto` defaults true with credentials; expected TLS host defaults to the endpoint host; system trust with no host check refused; credentials never sent without TLS unless `insecurePlaintextAuth` (tests only); a credentialed client always runs SCRAM whatever the pre-TLS ConnectResponse says; pre-TLS refusals → Backoff, never terminal; session-fatal notices accepted only sealed; `AuthServerFinal` must match the correlation and session ids. | X004, X006, X007, DR-14. |
| M3 | Client→broker AAD gains `u16 destination` (0 gateway, 1+w worker w); each receiver opens with its own id. | Binds a frame to its receiver; each receiver already has its own window (X009). |
| M4 | Enabled with ≥ 1 peer ⇒ shard mode; Enabled ⇒ no non-shard per-worker ingress; workers ≤ 252, peers ≤ 16, node ids ≤ 65535. Worker state `EnforcementMode = NotEnforcing | Enforcing{sink}`; `Enforcing` without a sink refuses every direct-ingress produce. | X012, X082, X083 (DR-13). |
| M5 | Producer ids are tagged to the principal: `pid = counter31 << 32 | SipHash-2-4(k_pid(K), counter ‖ principalId)[0..4]`, `k_pid(K) = HKDF-Expand(K.master, "rune-pid-tag", 16)`; minted under the current cluster key, verified under current then next; no held key verifies → `UnknownProducerId (28)` (client re-inits), not a strike; a non-verifying tag under a held key → 45, and 16 strikes end the session. Principal id is per-session (gateway `Session`, worker slot via `SessionAnnounce`), cached in `VerifiedPids[16]` per session. Allocator and persisted ceilings stay in counter space; reseed maps `pid >> 32` (pids < 2³² → floor 1). Dev/in-process: tag 0, no check. | A broker-local pid→principal map is wrong across brokers (InitProducerId is answered by the coordinator broker, produces by partition leaders elsewhere); the tag is stateless and cluster-wide (X037, DR-1/2/3). |
| M6 | Group member ids are 32 hex chars from the CSPRNG and bound to the owning session: rejoin / Sync / Heartbeat / Leave / OffsetCommit for a member of another session → `UnknownMember`; LeaveGroup needs READ on the group; OffsetFetch fetch-all omits topics the caller cannot READ (spec §2.1); TxnOffsetCommit v10 carries `memberId, generationId` and needs READ on each topic. | X039, X040, X041. |
| M7 | `SecurityServing` (control thread): `CatchingUp | Serving | Stale{sinceNs} | Halted`. Logins, −7 reads and security DDL answer new retriable **`AuthUnavailable = 48`** unless `Serving`. Input: admin→control `kA2cSecurityServing{u8 caughtUp, i64 leaderHw}`, posted on change: caught up ⇔ (leader and `SecurityAdmin` serving) or (follower, a fetch response from the current leader within F = `RUNE_SECURITY_MAX_STALENESS_MS` 1 000, and applied ≥ its HW, first one after boot). `Stale` longer than R = `RUNE_SECURITY_STALE_SESSION_END_MS` 10 000 ends authenticated sessions with session-level 48; a halt ends them with 48 (failover), not terminal 46 (amends D28). Parse requires F > `brokerLivenessTimeoutMs` + 500 ms and R > F. Clients back off and rotate seeds on 48. | X027 (boot, wipe, new broker, partition), X032 comes along. The lease condition is deferred (§5). |
| M8 | `authState = Anonymous` only on a never-bootstrapped cluster (`fakeSaltSeed` unset) that is `Serving`. `SecurityAdmin` refuses any DDL that would leave no enabled user effectively holding `ADMIN CLUSTER` (`InvalidRequest` "would leave no security admin"). | X028. Zero admins is never a desired state; the D3 window remains for a fresh cluster. |
| M9 | Authorization of an id at or above the broker's applied topic horizon answers `NotLeader` before any 45 (gateway: applied `nextTopicId`; worker: a worker-wide `TopicHorizon` op). GetTopicSchema checks only the object's own kind. DefineTopic with a descriptor on an existing topic needs ALTER + DESCRIBE. | X046, X047, X048. |
| M10 | Live-change robustness that needs no fence mechanism: a Subscribe waiting on record egress is dropped when its subscription ends; no MDC fallback under auth (`Internal` "record egress unavailable"); `-2/-3` end-reads are per-session pending state, never dropped; revoked / failed sessions enter `Closing{deadline 2 s}` (drop inbound, drain the spill, then close); a held security OK past `RUNE_SECURITY_GATE_DEADLINE_MS` (5 000) answers `Internal` "committed at offset N; enforcement not confirmed". | X015, X017 (part), X018, X020, X021 (part). Each piece is part of the long-term design; the fence acks that complete X016/X017/X019/X021 are deferred. |
| M11 | Login throttle: a first leg charges a pending failure to (user, host), host and user; success refunds; abandoned legs stay charged; `check` at both legs; ≤ 4 `AwaitingFinal` per (user, host), ≤ 64 per host; per-user backoff (20 free, then `min(50 ms·2^(k−1), 2 s)`, bypassed for a (user, host) with a success in 15 min); SipHash tables with a per-process key; source host from the fragment's own `aeron::Header` image; both fake slots always computed. | X063, X064, X065 (+ X067). |
| M12 | Peer links: unauthenticated input never changes link state — `UnknownEpoch` frames are counted only (a rekey starts only after 1 s with no authenticated frame from that peer while frames arrive); `Refuse`, bad `macB` and NoLink are logged, rate-limited, ignored; an `Established` initiator keeps its keys until a new exchange completes; ≤ 1 new exchange per 200 ms per peer; handshake `Out` uses fixed buffers; the incarnation high-water refusal is deleted. Receivers accept only their role's sender id before any crypto (consensus 0, legacy 1, admin 2, worker w → 3+w) and derive only that key; the legacy transport commits the replay window only after a non-ABORT dispatch. | X077, X078, X080, X081, X085, X086. These rules survive the deferred v2 handshake unchanged. |
| M13 | `dataDir/__security` 0700, its files 0600 (per-log file mode); a group- or world-readable cluster key file refuses to start (launchers mount 0400). Unauthenticated-sender log lines (worker decrypt failure, require-TLS refusal, bad bootstrap proof, login failures) use the existing 1/1024 rate limit plus a counter. | X102, X103. |
| M14 | VLS Part B as specified (`2026-10-19-view-read-lease-and-sink-plane-design.md` Part B, default B.6 = replica-less sinks); under auth a sink produce is 45 before the `InvalidRequest` refusal. | The only way to close Critical X188. If the user chooses B.6 = keep a changelog, tasks 16a–16d switch to its §B.4 design. |
